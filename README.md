# Dashboard de anuncios de vehículos usados

## Descripción del proyecto

Este proyecto consiste en desarrollar una aplicación web interactiva para explorar datos de anuncios de vehículos usados en Estados Unidos.

El dashboard permite visualizar los registros del conjunto de datos y analizar la distribución de los precios y la relación entre el kilometraje y el precio de los vehículos.

## Archivos del proyecto

- `app.py`: código de la aplicación web desarrollada con Streamlit.
- `vehicles_us.csv`: conjunto de datos utilizado para el análisis.
- `requirements.txt`: librerías necesarias para ejecutar la aplicación.
- `notebooks/EDA.ipynb`: notebook con el análisis exploratorio de datos.
- `.gitignore`: archivos y carpetas excluidos del control de versiones.

## Tecnologías utilizadas

- Python
- Pandas
- Streamlit
- Plotly
- Jupyter Notebook

## Ejecución local

Para ejecutar la aplicación en tu computadora:

1. Instalar las librerías:

   `pip install -r requirements.txt`

2. Ejecutar la aplicación:

   `streamlit run app.py`
